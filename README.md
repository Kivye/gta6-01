Palmshade Heat: an original open-world crime game that plays in a desktop browser from static files. Explore the sun-soaked city of Palmshade on foot and by car across 3 districts, steal and fence 12 car models through the chop-shop loop, run 5 chained story missions, and outrun a 5-star wanted system with live traffic, pedestrians, combat, a minimap HUD and a local save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
