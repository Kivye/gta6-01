# PALMSHADE HEAT

A tiny open-world crime game — Three.js, procedural Web Audio,
zero build step, zero assets. Steal cars, run eight story jobs, dodge the PSPD,
climb from Nobody to Palmshade Legend.

## Play

Open `game/index.html` via the bundled server (`node main.ts`, port 8080) or any
static file server. Click **START ENGINE**.

- **WASD** move · **E** enter/exit car · **mouse / Space** shoot · **Shift** nitro / sprint
- **R** radio · **M** mute · **N** Neon Night · **P** pause + career stats
- **Z / X / C** crew abilities · **1–3 / wheel** weapons · **T** street race
- **B** buy property · **Y / U** respray / favourite car at the garage

## What's inside

- A 3-district city (Marina, Old Town, The Heights), traffic, pedestrians,
  district standing, and a 5-star wanted system: cruisers, AIR-1 helicopter,
  roadblocks, SWAT-1, spike strips.
- Eight story missions, three street races, eight stunt ramps, three income
  properties, a respray garage, a Gun Van armoury, three weapon slots with
  real ammo, layered procedural audio, career stats, local save.
